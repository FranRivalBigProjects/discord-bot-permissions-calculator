How Discord Permission Integers Work

Discord represents each permission as a power of two (a bit flag). To combine multiple permissions into one number, Discord adds the bit values together. This calculator handles that math for you and also reverses it, so you can paste a permission integer and see exactly which permissions it grants.

These numbers are commonly used when building a bot invite link in the format https://discord.com/api/oauth2/authorize?client_id=YOUR_CLIENT_ID&permissions=YOUR_NUMBER&scope=bot

Why the Numbers Get So Large

Discord has added dozens of granular permissions over time (threads, events, application commands, and more), so the highest bit values now exceed what a standard 32-bit integer can hold. This tool uses arbitrary-precision math internally so large permission sets still calculate correctly.
